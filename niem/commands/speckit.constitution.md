## NIEM Constitution Guidance

- Use the resolved constitution template, including its NIEM governance addendum,
  to establish principles for exchanges actually in scope.
- Preserve authored principles and the normal amendment/versioning process.
  Explicitly resolve conflicts between proposed NIEM principles and current
  governance rather than silently imposing a new baseline.
- Capture semantic ownership, reuse/extension policy, compatibility decisions,
  source provenance, and evidence required for conformance claims. Where a
  release is not yet selected, record that decision as deferred instead of
  pretending NIEM 6.0 was adopted.
- Only update the constitution. Do not create schemas, rewrite dependent
  templates, install tools, or execute a deferred implementation request.
